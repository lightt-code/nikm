# LIGHT — Portfolio

Static one-page portfolio site. No build step is required.

## Structure

- `index.html` — page structure and content
- `style.css` — visual styles and existing animations
- `script.js` — stars, music control and portfolio carousel
- `assets/girl.png` — supplied character image with transparent background
- `assets/music.mp3` — local background music

## GitHub Pages

1. Upload the contents of the `LIGHT-Portfolio` folder to the repository.
2. Keep the `assets` folder in the same directory as `index.html`.
3. Enable GitHub Pages for the repository/branch.
4. Open the published Pages URL.

All newly added media uses relative paths, so it is loaded from the GitHub Pages project itself.
