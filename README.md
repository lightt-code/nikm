# LIGHT — CEO Portfolio

Лёгкая версия сайта для GitHub Pages.

- Интерактивная 3D-визитка CEO вместо изображения девушки.
- Управление визиткой мышью, touch и клавиатурой.
- Фиолетовая тень/свечение и оборот на обратную сторону.
- Музыка сохранена, MP3 оптимизирован для меньшего размера.
- 4 изображения портфолио оптимизированы для веба.
- Без внешних библиотек и сборки: достаточно загрузить файлы в репозиторий.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.
`index.html` должен находиться в корне публикуемой папки.
